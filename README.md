# Zotero-Hide-Scrollbar
A Zotero plugin for hiding the pdf viewer scrollbars
## Features
- Disables the scollbars from the PDF viewer

| Before  | After |
| ------------- | ------------- |
|<img width="1920" alt="Light With Scroll" src="/extra/light_scroll_yes.png"/> | <img width="1920" alt="Light No Scroll" src="/extra/light_scroll_no.png"/> |

## How to Use
- The plugin adds a single toggle under the `Tools` menu options named `Hide PDF Scrollbars`
    - If the toggle is checked then the scrollbars are hidden, if it isn't checked then, they are visible
    - <img src="/extra/tools.png" alt="Tools" width="300">

## Behavior
- The plugin allows to toggle hide both the horizontal and vertical scrollbars from the Zotero `.pdf` file viewer
    - **Note**: When viewing other files like e-books or websites the scrollbars should still remain 
- This plugin is mainly intended to function as a supplementary plugin to the [Zotero-Focused-Mode](https://github.com/dschaehi/Zotero-Focused-Mode) plugin which doesn't hide the scrollbars

## Installation
1. Download the `hide-pdf-scroll.xpi` file from the [releases page](https://github.com/haraldsu/zotero-hide-scrollbar/releases/tag/v1.0.0) or click [here](https://github.com/haraldsu/zotero-hide-scrollbar/releases/latest/download/hide-pdf-scroll.xpi)
    - **Note**: On firefox you might have to right click the `.xpi` file and then press `Save Link As` -> `Save` 
2. In Zotero, go to `Tools` -> `Plugins` -> Press the gear icon -> click `Install Plugin From File`
3. Select the downloaded `.xpi` file

## Requirements
- Tested on Zotero 9.0.3
